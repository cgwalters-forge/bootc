## Failed-plan diagnostics

Set `BOOTC_TMT_FAILURE_DIAGNOSTICS=1` on the host running `cargo xtask run-tmt`
to collect best-effort diagnostics before failed-plan VM cleanup. It is off by
default because additional guest journal collection can disclose guest data and
delay cleanup. Successful plans do not collect. `--preserve-vm` still collects
on failure but skips removal; original test results and reboot waits are unchanged.

The `failure-diagnostics.json` manifest lives beside bcvk's existing captures in
`/var/tmp/tmt/<vm-name>/` (or the existing `--log-dir` / `TMT_LOG_DIR` override).
The existing CI upload of `/var/tmp/tmt` retains it; retain custom directories
yourself. Start with existing `console*` and `journal*` files, including rotated
journals: these are inventoried in place, not replaced by another capture stream.
Missing/empty captures and old/unavailable bcvk capture support are explicit.

The manifest identifies the plan, VM, failed test, observed reboot count and
step. Unavailable evidence is `unknown`; timeout evidence is limited to TMT's
exact `reboot timeout` result note or `RebootTimeoutError:` exception, not arbitrary
guest timeout text. Referenced log read failures, missing/oversize files, rejected
traversal and escaping symlinks are reported. VM inspect output is reduced to an
allowlist of state and numeric memory, CPU and SSH-port fields, never raw JSON,
labels, image paths or SSH key material.

A single SSH probe precedes a single previous-boot `journalctl -b -1` fetch,
limited to 1000 lines. Each command uses GNU `timeout` with a 10-second deadline
and 1-second kill grace; missing tools, unreachable SSH and absent journals are
reported without replacing the failing result. Input files and command output
are capped at 256 KiB; at most 64 results, 16 referenced logs total and 128 capture
directory entries are examined. Collection adds no reboot retry or longer wait
and does not classify or fix a guest boot failure. Review guest journals before
sharing artifacts; arbitrary secrets in guest journals are not redacted.
